### Bugs or weaknesses introduced by AI and how they were resolved

- **Initial audit model was too narrow** (row #2): it recorded decisions only. After the requirement expanded, it was replaced with a multi-event `AuditRecord`, an abstract repository port, a JSONL repository, and a DI-driven service.
- **Initial AI validator failed open in governance-critical cases** (rows #3 and #10–12): it accepted Role 1 defaults for incomplete AI JSON, skipped state checks without context, treated unsafe conflicts as warnings, inferred a missing rule id, validated operator names without semantic compatibility, and returned unexpected exception details. A 129-case suite exposed 23 gaps; all were fixed and retained as passing regression tests.
- **Early inline shell smoke commands failed because escaped newlines were interpreted incorrectly.** Verification moved to temporary scripts, which were deleted after execution; repository code was unaffected.
- **Windows console-script installation warnings occurred for development tools.** Python modules were still verified through `python -m ...`; no application workaround was introduced.
