### Bugs the AI introduced and how they were resolved
- **Score-mode confidence collapsing to `0.00`** (row #3): caused by including a deliberately unbounded catch-all threshold (e.g. `(-1e9, "REJECT")`) in the confidence-normalization span. Fixed by excluding any threshold with `abs(bound) >= 1e6` (treated as an infinity sentinel) from the boundaries used to compute confidence. Covered by a regression test.
- **`apply_operator` requiring an `expected` argument even for unary operators** (row #5): made calls like `apply_operator("is_empty", None)` raise `TypeError`. Fixed by defaulting `expected=None` in the signature — a safe, intentional API change consistent with how unary operators (`is_empty`, `is_true`, …) are meant to be called.
